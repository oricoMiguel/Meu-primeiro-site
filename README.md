## 📌 Sobre o Projeto

Este projeto consiste numa aplicação web completa voltada para a exibição de produtos, gestão de encomendas e contactos. Inclui suporte a scripts interativos em JavaScript e janelas pop-up detalhadas para cada produto.

---

## 📄 Páginas do Site

- **`index.html`**: Página principal / Apresentação do site.
- **`produtos.html`**: Catálogo principal de produtos.
- **`pop_produtos.html`**, **`pop_produtos1.html`**, **`pop_produtos2.html`**: Modais/Janelas pop-up com detalhes dos produtos.
- **`encomendas.html`**: Formulário e página para realização de pedidos/encomendas.
- **`contatos.html`**: Página de contacto e apoio ao cliente.
